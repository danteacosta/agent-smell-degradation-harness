# Recovered public evidence

This packet makes three previously private result rows recalculable without model calls. Run `make reproduce` from the repository root. The command checks the SHA-256 receipt for `rows.json`, recomputes counts from published rows, and returns nonzero when those counts disagree with the reported values.

`rows.json` contains normalized projections of four sealed private packets. Each row identifies its original JSON file and field; each cohort retains the source-file hashes, packet identifier, full private receipt hash, and number of receipt-listed files verified at export. Those private originals are not included, so their receipt hashes establish a custody link, not independent public verification of all screenshots or judgments. The public receipt covers the exported JSON bytes.

Ordinal 0 means the expected behavior was demonstrated; 2 means material functional loss or a wrong persisted result. Unknown remains unknown and contributes to the planned denominator. The numeric 0–3 rubric does not by itself validate equal spacing or human agreement. All these results remain exploratory and `confirmatory_eligible` is false.

The aggregate block of eleven obligations and the sixty historical old/new pairs still lack a complete public machine-readable source. Later successor packets must not be substituted for missing originals.
