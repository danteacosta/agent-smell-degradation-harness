# OpenProject Remaining work E2E pilot

Status: instrument construction before any generation or outcome inspection.

The case is `openproject-derive-remaining-hours` from the prospectively screened
multi-obligation pool. Its mapping received unanimous ACCEPT from the isolated
three-model panel before oracle construction. This is one previously unexecuted
obligation in an already represented project, not a new project or a confirmatory
sample.

## Acceptance contract

Given a work package with Work already stored as 10 hours and no Remaining work,
when a user enters 40% Complete, saves, and reloads the page, then Remaining work
is visibly 6 hours. Work remains 10 hours and % Complete remains 40%. A second
bounded fixture uses Work=20 hours and % Complete=25%, expecting 15 hours, to
reject an implementation that hard-codes the first example.

The browser oracle reports the target result separately from the two controls.
Missing, duplicated, or unusable controls, script errors, failed reloads, and
malformed reports are unknown or invalid, never target-only failures. A target
failure counts only when both controls pass and the page is evaluable.

## Prospective collection

One frozen page owns the interface, initial state, save mechanics, and reload
mechanics. The generator can replace exactly one behavior marker. It receives
one of three requirement texts: A states the derivation, B restates it without
changing meaning, and C removes only the derivation while retaining the Work
and % Complete preservation obligations. The prompt must not contain test
assertions or the C deletion rationale.

Two Codex model configurations (`gpt-5.6-luna`, `gpt-5.6-sol`) each run A, B,
and C three times in fresh contexts: 18 scheduled generations. One seed fixes
the randomized order before dispatch. All generations finish before any output
is opened in the browser. Errors, invalid outputs, and unknown browser results
remain in the 18-position denominator. No retry, repair, or replacement is
permitted in this packet. C−A is the target-failure contrast; B−A diagnoses
wording sensitivity. Report every model/arm cell, recovery in C, and bounds for
missing outcomes. The earlier OpenProject pilot remains a separate stratum.

## Before dispatch

1. Bind the exact source and license bytes and the A/B/C deletion span.
2. Qualify the browser oracle in the final pinned image with two correct

4. Freeze the request bytes, image and runtime identities, order, models,

The outcome is exploratory browser evidence. It does not estimate the formal
human-severity H1 endpoint or evaluate H2's pre-final trace classifier.
