# Follow-up: construct validity and saved-artifact robustness

Status: continuation of the authorized paired-evidence review; no new provider
collection or source-corpus promotion in this step.

## Decision and alternatives

The completed run has three original intents but one manipulation: deletion of
an explicit policy sentence. Repeating it with a second model adds configuration
coverage, not smell-family coverage. Immediately building ten executable cases
risks giving unsupported taxonomy labels to the same manipulation. First audit
the saved artifacts and publish a literature-to-intervention coverage matrix.
This is the selected, bounded next step.

## Acceptance contract

1. Given the original receipt, verify every listed hash before reading generated
   code for execution. Preserve the original evidence directory unchanged.
2. Given all 18 saved responses, execute every artifact against a separately
   frozen post-hoc audit plan in the existing isolated Linux container. No model
   calls, repairs, discarded artifacts or changes to the original oracles.
3. Given the original policies, audit access on both Boolean inputs; discount
   on integers 0..200 plus 69.99 and 70.01; token on ages 0..30 plus 14.5,
   14.999 and 15.001, each crossed with both values of used. Exclude out-of-domain
   negative ages/totals. Total: 1,638 checks across the same 18 artifacts.
   Freeze discount expectations as Python `min(total * 0.1, 7)` and retain the
   executor's exact equality comparison. A mathematically equivalent division
   can round differently: inspect actual/expected for each failure and separate
   numeric-representation mismatches from a missing cap. Only an actual numeric
   result above 7 on an input above 70 is evidence of the omitted upper bound.
   The audit does not establish correctness of monetary rounding conventions.
4. Given audit outcomes, report per-artifact and per-intent pass/fail/error
   counts. A wider grid is a diagnostic, not new generation, independent
   replication, prevalence or confirmatory evidence. Stop on a containment
   precheck failure; preserve partial reports on an execution failure.
5. Given the primary literature, distinguish named smells, local interventions
   and observed effects. Publish at least ten catalog entries with an explicit
   execution status. Do not equate Paska's syntactically incomplete condition
   with deletion of an entire policy rule.
6. Update repository research notes and the existing Drive report/slides with
   the audit outcome and construct-validity caveat. Preserve historical records,
   null contrasts and the source-derived lane's quarantine.

## Scientific boundaries and next collection

The access output enum and token argument named `used` retain cues about the
omitted behavior. Their null contrasts are conditional on these scaffolds;
they are not proof of robustness under removal of all contextual information.
Do not alter that interface post hoc and pool results with the original run.

The audit is assistant-conducted, not independent human annotation. Before a
broader study, independently review each smell label, exact changed span,
full intended contract, valid input domain, target and preserved-behavior tests,
scaffold cues and allowed interpretations. Freeze acceptance/rejection of cases
before observing new model outcomes. Keep semantics-preserving rewrites as
controls; include ambiguity/clarification outcomes where an oracle would
otherwise invent a missing policy. A second model using Codex is a second model
configuration, not a second provider. H1/H2 gates remain unchanged.
