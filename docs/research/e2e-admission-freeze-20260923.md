## Endpoint decisions

Persistence is admitted only for ordinary **visible edit-mode restoration in a
second same-origin page**, while the first page remains open. A missing or hidden
restored todo makes the target unknown. This neither establishes absence of
serialized editing bytes nor tests actual same-page reload or full source
compliance. The admitted endpoint is an exploratory behavioral proxy; its narrow
meaning must remain attached to every result.

Mark all is deferred: the current runner can fail a retained hidden checked
master but pass when the master is removed. Equivalent visible states can receive
different verdicts. Resolve hidden/removed/replaced-control semantics and qualify
them before admission. Its earlier 11-control qualification is preserved.

StrictDoc is deferred: the finite date lexicon can reject a valid unfamiliar
format, and the source does not independently establish first render as the
generation event. Resolve event interpretation and unassessable-date handling
before admission. Its earlier 21-control qualification is preserved.
