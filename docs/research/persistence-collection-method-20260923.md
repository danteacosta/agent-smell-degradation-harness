# Persistence UI collection method

The execution successor binds the exact PR72 A/B/C prompts and randomized 18-slot
schedule to a separate collector, Codex executable and qualified offline browser.
The parent remains immutable. Source/prompt review and endpoint admission were
completed before generation. This is the admitted **second-page visible edit-mode
restoration** proxy, not absence of serialized editing bytes or same-page reload.

## Configuration and custody

- One TodoMVC intent; A/B/C × two model labels × three repetitions = 18 positions.
- Labels: `gpt-5.6-luna`, `gpt-5.6-sol`; low reasoning; sequential calls; 180-second
  completion timeout. The CLI does not expose immutable model snapshot identity.
- Explicit app executable: Codex CLI `0.155.0-alpha.9.2`, SHA-256
  `9280c0754e8f1f6b72f495d30c8c82a006dbc4995bf0492916fa0901f6bfd1f9`.
  The older system CLI was not used.
- Saved ChatGPT subscription authentication, no API-key fallback or quota reset.
  Consumption is not measured as a zero-dollar API price. The capacity tool
  reported ordinary usage allowed with 9% weekly usage at preflight; this is not
  a guarantee that the entire collection will fit future capacity.
- Fresh empty temporary working directory and ephemeral session per request;
  user config, project documents, shell/web/browser/tools, skills, MCP/apps and
  multi-agent execution disabled in the frozen provider. Only the prompt goes to
  stdin. Metadata about arm, oracle and paired alternatives is not supplied.
- Two separate availability calls returned `READY` with distinct thread IDs.
  They are preflight, not experimental observations. Fake-CLI integration also
  verifies distinct empty working directories, required flags, exact stdin,
  environment sanitation and cleanup.
- No collection resume, wrapper retry, output repair or regeneration. Internal
  transport retries are not observable. Provider failure stops remaining calls;
  malformed output remains unknown. Attempt records and their directory links
  are flushed before invocation, and a failed flush prevents invocation.
- Raw transport captures are limited to 2 MB per stream with truncation metadata.
  The extracted answer is stored unchanged. The predeclared artifact rule accepts
  at most 200000 UTF-8 bytes of standalone raw HTML, with optional doctype,
  explicit opening/closing html tags and outer whitespace. Markdown fences,
  JSON envelopes, leading explanation and trailing prose are not repaired.
- Every generation finishes or dispatch stops before any generated HTML is run.
  Offline Docker execution exposes only `app.html`; independent browser reports
  and three screenshots are retained. Missing/hidden restored todos keep the
  target unknown, even if other assertions fail.

## Analysis and presentation

Report all 18 planned positions, separating target-only, mixed, non-target-only,
null, interface-invalid and missing outcomes. Unknown outcomes give worst-case
failure-rate bounds over the fixed planned denominator. Those bounds are not
confidence intervals. Three repetitions are nested within one requirement and
cannot create independent requirements or projects.

Illustration selection was fixed before behavioral results: first repetition of
`gpt-5.6-luna`, arms A and C. Preserve absence if either is not evaluable rather
than selecting a better-looking contrast. Screenshots corroborate observations;
the trusted browser assertions, exact generated bytes and receipts define the
reproducible endpoint record.

This execution cannot establish a general smell effect, confirm H1/H2, or supply
the requested cross-project diversity. Mark all and StrictDoc remain deferred.
